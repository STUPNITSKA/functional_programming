# Лабораторна №2. Музичний каталог

Варіант 14. Мета — побудувати конвеєр перетворень над треками за допомогою `map`, `filter`, `lambda`, композиції функцій та окремої агрегації через `reduce`, не змінюючи вхідні записи.

- `core.py` описує трек через `TypedDict`. Конвеєр рахує суму прослуховувань `total`, підсилює її для вибраного жанру, відкидає непопулярні треки з `total` менше порогу, сортує за спаданням `total`, а при рівності за зростанням `id`, і бере Top-N. Кожен крок повертає нові словники.
- `compose` застосовує функції справа наліво, `pipe` — у порядку передачі, `juxt` застосовує кілька функцій до одного значення. Через `juxt` зроблено ключ сортування з двох полів, а конвеєр `build_pipeline` зібрано через `compose`.
- `reduce_stats` через `reduce` рахує `count`, `listens_sum` та `avg_listens`. Для порожнього списку всі значення нульові.
- `app.py` читає JSON, приймає параметри командного рядка і друкує рейтинг та статистику. `main.py` запускає `main()` з `app.py`.
- `tests/test_core.py` перевіряє Top-N, сортування при рівних сумах, незмінність вхідних даних, агрегацію, композицію і запуск програми.
- `sample_data.json` містить приклад треків, `ASSIGNMENT.md` — умову, `pyproject.toml` — налаштування black, ruff, mypy і pytest.

Для запуску потрібен Python 3.10 або новіший. З кореня репозиторію виконай `python Lab_02/main.py`.

Щоб запустити програму й усі перевірки, перейди до папки лабораторної.

```bash
cd Lab_02
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python main.py
python main.py --data sample_data.json --top 2 --boost-genre Джаз --factor 1.2
python -m pytest
python -m mypy .
python -m black --check .
python -m ruff check .
```

Без параметрів використовується `sample_data.json`, жанр «Рок», коефіцієнт 1,1, поріг 100 прослуховувань і Top-3. У рейтинг потрапляють треки з `id` 2, 1 і 4: разом 990 прослуховувань, у середньому 330. Жанр змінюється через `--boost-genre`, коефіцієнт — через `--factor`, поріг — через `--min-listens`.
