# Лабораторна №1. Вартість навчальних курсів

Варіант 14. Програма отримує реєстрації на курси: курс, ціну, статус студента і кількість курсів. До ціни застосовується студентська знижка, якщо це студент, і пакетна знижка, якщо записано на потрібну кількість курсів або більше. Правила знижок поєднуються по черзі, після них нараховується податок. Вхідні реєстрації не змінюються, результат записується в нові словники з полем `total`.

- `core.py` містить чисті функції без `print`, глобальних змінних і роботи з часом. `process_registrations_pure` приймає всі ставки явно. Фабрика `make_processor` приймає три функції через `typing.Callable`: фільтр реєстрацій, знижку і податок.
- `make_student_discount` і `make_package_discount` повертають правила знижок, `compose_discounts` поєднує їх, `make_tax` повертає функцію податку. Поточний час передається в `stamp_total` ззовні. Також є `compose` і `make_multiplier`, а список результатів створюється через списковий вираз.
- `app.py` містить `main()`, яка задає демонстраційні реєстрації і правила, а `render_report` друкує результат. Ставки обрані для прикладу.
- `main.py` запускає функцію `main()` з `app.py`.
- `tests/test_core.py` перевіряє повторюваність результату, відсутність мутацій, заміну правил і розрахунки.
- `report/lab1.pdf` містить звіт про виконання лабораторної.

Для запуску потрібен Python 3.10 або новіший. З кореня репозиторію виконай `python Lab_01/main.py`.

Щоб запустити програму й усі перевірки, перейди до папки лабораторної.

```bash
cd Lab_01
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python main.py
python -m pytest
python -m mypy .
python -m black --check .
python -m ruff check .
```
