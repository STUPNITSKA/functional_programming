# Лабораторна робота №1
## Основи функціонального програмування у Python

### Варіант №7 — Облік електроенергії

Програма призначена для розрахунку споживання електроенергії та суми до оплати.

### Вхідні дані

- попередній показник лічильника;
- поточний показник лічильника;
- тарифна група;
- тариф за 1 кВт·год.

### Реалізовані функції

У файлі `core.py` реалізовано чисте функціональне ядро:

- `calculate_consumption()` — обчислює споживання електроенергії;
- `calculate_cost()` — обчислює вартість спожитої електроенергії;
- `make_tariff()` — фабрика тарифних функцій;
- `no_benefit()` — політика без пільги;
- `calculate_payment()` — розраховує кінцеву суму до оплати.

Для параметризації обчислень використано `typing.Callable`.
